# the_snake

## Описание проекта

**«Изгиб Питона»** — классическая компьютерная игра «Змейка», реализованная на языке Python с использованием библиотеки `pygame`. Игрок управляет змейкой, которая движется по игровому полю, разделённому на клетки, и увеличивается в длину, «съедая» появляющиеся на экране яблоки. При столкновении змейки с самой собой игра начинается заново, а при выходе за границу поля змейка появляется с противоположной стороны. Проект написан на принципах объектно-ориентированного программирования: игровые объекты (змейка и яблоко) описаны в виде классов с атрибутами и методами. Это учебный проект студента ИТМО Коновалова Кирилла по курсу Python.

## Настройка окружения

Для запуска игры нужен Python 3 и библиотека `pygame`. Рекомендуется работать в локальном виртуальном окружении.

### 1. Создание виртуального окружения

```bash
python3 -m venv .venv
```

### 2. Активация окружения

```bash
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
.venv/bin/pip install -r requirements.txt
```

Либо установить `pygame` напрямую:

```bash
.venv/bin/pip install pygame
```

### 4. Запуск игры

```bash
.venv/bin/python the_snake.py
```

### Нюанс: сборка pygame из исходников

Для новых версий Python (например, **3.14**) готового wheel-пакета `pygame` нет, поэтому `pip` собирает его из исходников. Для этого нужны компилятор и SDL2-библиотеки разработчика. Подробнее [тут](./docs/how_to_build_pygame.md)

### Ключевые классы

- `GameObject` — базовый класс игровых объектов; содержит общие атрибуты (`position`, `body_color`) и заготовку метода `draw`.
- `Apple` — класс яблока, наследуется от `GameObject`; появляется в случайной клетке поля.
- `Snake` — класс змейки, наследуется от `GameObject`; управляет движением, отрисовкой и сбросом.
- `PyGameWrapper` — обёртка над pygame: игровое окно, обработка клавиш (`handle_keys`), таймер.

Классы объектов описаны в `game_objects.py`, точка входа — в `the_snake.py`.
