# the_snake

## Установка зависимостей

Для запуска игры нужен `pygame`. Установите его в локальное виртуальное окружение `.venv`:

```bash
python3 -m venv .venv
.venv/bin/pip install pygame
```

### Нюанс: сборка pygame из исходников

Для новых версий Python (например, **3.14**) готового wheel-пакета `pygame` нет, поэтому `pip` собирает его из исходников. Для этого нужны компилятор и SDL2-библиотеки разработчика. Подробнее [тут](./docs/how_to_build_pygame.md)
