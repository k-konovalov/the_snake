Тема 5/6: Проект «Изгиб Питона» → Урок 1/4

Это первый проект, который вы выполните на своём компьютере и отправите на проверку через GitHub.

Во время работы над финальным проектом потребуется сделать три шага:

1. Получить и развернуть заготовку проекта на своём компьютере.
2. Выполнить задание, протестировать свою программу локально.
3. Отправить выполненное задание на проверку.

## С чего начать

Привяжите свой аккаунт GitHub к своему аккаунту в Яндекс Практикуме. Для этого в верхней части страницы урока с финальным заданием есть специальная кнопка:

![](https://pictures.s3.yandex.net/resources/image_1734437966.png)

После того как вы свяжете аккаунты, эта кнопка изменится — она будет запускать процесс проверки задания:

![](https://pictures.s3.yandex.net/resources/image_1734437982.png)

После того как вы свяжете свои аккаунты на GitHub и в Яндекс Практикуме и войдёте в урок с заданием, **в вашем аккаунте** на GitHub появится новый приватный репозиторий *the\_snake*:

![](https://pictures.s3.yandex.net/resources/image_1734437999.png)

Клонируйте этот репозиторий на свой компьютер.

В репозитории *the\_snake* лежит файл для домашнего задания, который называется *the\_snake.py*, набор автоматических тестов и некоторое количество служебных директорий и файлов.

```markdown
└── the_snake
    ├── tests
    │   ├── conftest.py
    │   ├── test_code_structure.py
    │   └── test_main.py
    ├── .gitignore
    ├── README.md
    ├── pytest.ini
    ├── requirements.txt
    ├── setup.cfg
    └── the_snake.py  <-- Пишите код в этом файле
```

В директории *the\_snake* разверните и активируйте виртуальное окружение.

BASH

```bash
# Команда для Windows:
python -m venv venv
source venv/Scripts/activate

# Команда для Linux и macOS:
python3 -m venv venv
source venv/bin/activate
```

Содержимое директории с проектом должно стать таким:

```markdown
└── the_snake
    ├── tests/
    ├── venv/      <-- Здесь должна появиться папка с виртуальным окружением
    ├── .gitignore
    ├── README.md
    ├── pytest.ini
    ├── requirements.txt
    ├── setup.cfg
    └── the_snake.py  <-- Пишите код в этом файле
```

Установите зависимости проекта:

BASH

```bash
pip install -r requirements.txt
```

Теперь всё готово, можно выполнять домашнее задание!

## Проверка и работа над ошибками

После того как задание будет выполнено, проверьте свою работу линтером на соответствие правилам оформления кода. Это можно сделать через редактор кода, либо через терминал, выполнив команду `flake8` из директории проекта *dev/the\_snake*.

После этого из директории проекта запустите команду `pytest`: автоматические тесты, написанные для задания, проверят, правильно ли работает ваш код. Убедитесь, что тесты проходят успешно.

Если линтер или тесты обнаружат ошибку, исправьте код и вновь выполните обе проверки.

## Отправка задания на платформу

Следующий шаг — отправить выполненную и проверенную работу на GitHub. Там ваша работа будет повторно проверена линтером и тестами (уже без вашего участия, автоматически), а затем задание проверит специалист-ревьюер.

Чтобы отправить код **в ваш репозиторий** на GitHub, выполните команды:

- `git add .` — добавить файлы в индекс отслеживания Git;
- `git commit -m 'текст комментария'` — создать коммит (он будет создан локально), зафиксировать изменения;
- `git push` — запушить коммит на удалённый сервер.

Затем нажмите кнопку «Проверить задание» вверху страницы с заданием.

Будьте внимательны: файлы и директории вашего проекта нужно разместить в главной папке репозитория, который вы склонировали.

Если проект не удаётся отправить обычным способом и платформа предлагает загрузить проект архивом, ваш архив должен соответствовать правилам:

- быть строго **в формате ZIP**;
- размер архива должен быть **меньше 4 MB**.

Надёжнее всего будет скачать ZIP-архив с проектом из вашего репозитория на GitHub:
